# Core Canon

This folder contains the foundational facts of **Beyond the Firmament**.

Core Canon should change slowly. It includes the origin of the Remnants, the Peregrine, major technologies, the early voyage, physical constraints, and other facts that all canon work should respect.

Planned sections include:

- Origin and Earth
- The Founders
- The Peregrine
- The Biological Ark
- Escape from Earth
- Mars Line
- Asteroid Belt
- Jupiter Assist
- Sun Dive
- Outer System and Heliopause
- The Long Voyage
- Alpha Centauri
